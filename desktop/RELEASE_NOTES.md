## このバージョンの変更点

- 取引所と同じような一部決済ができるようになりました
  - 注文パネルの利確に割合（100 / 75 / 50 / 33 / 25%）。100% 未満なら「利確2」で残りを別の価格に置けます
  - 指値・逆指値に「決済のみ（reduce-only）」。ポジションを減らすだけで、反対のポジションは作りません
  - ポジションの「一部決済…」（成行・指値・逆指値、割合か数量で指定）、「建値に損切り」、トレーリングストップ（トレール幅）
  - チャートの右クリックで、その価格で半分・1/3・全部を利確／損切り
  - ストラテジー（AI トレーナーが作るものも）から分割利確・一部決済・トレールを使えます

## ダウンロード

`TradeReplay-…-windows-x64.zip` を展開して `TradeReplay.exe` を実行してください（インストール不要）。
「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。

## AI トレーナー

初めて使うときは、画面の案内に従ってください。Claude Code のインストールは自動で行います。ログインには Claude の有料プラン（Pro / Max など）か Anthropic Console のアカウントが必要です。
