## ダウンロード

`TradeReplay-…-windows-x64.zip` を展開して `TradeReplay.exe` を実行してください（インストール不要）。
「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。

## AI トレーナー

初めて使うときは、画面の案内に従ってください。Claude Code のインストールは自動で行います。ログインには Claude の有料プラン（Pro / Max など）か Anthropic Console のアカウントが必要です。

ブラウザ版: https://kuroron000234.github.io/trade-replay/
