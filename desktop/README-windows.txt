Trade Replay（Windows 版）

■ 起動
TradeReplay.exe をダブルクリックすると、ブラウザで Trade Replay が開きます。
黒い窓（サーバー）を閉じると終了します。インストールは不要です。

「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください
（署名していない個人製作のアプリのため表示されます）。

■ AI トレーナー（任意）
画面下の「AI トレーナー」タブで、Claude と話しながら売買ルールを作ったり、
取引の振り返りを相談したりできます。初めて使うときは、画面の案内に従ってください。
  1. 「セットアップ」を押すと、Claude Code（Anthropic 公式の CLI）を自動でインストールします。
     管理者権限は不要です。インストール先は %USERPROFILE%\.local\bin です。
  2. 「ログイン」を押すと窓が開き、ブラウザで Claude へのログインを求められます。
     Claude の Pro / Max などの有料プラン、または Anthropic Console のアカウントが必要です
     （無料プランでは使えません）。使った分はそのアカウントの利用枠から差し引かれます。
AI トレーナーを使わなければ、Claude Code は不要です。

■ データの保存場所
取引記録や設定はブラウザ内（http://127.0.0.1:8765 のサイトデータ）に保存されます。
ブラウザのサイトデータを消すと記録も消えます。記録は「トレード記録」タブから書き出せます。

■ 注意
これはデモ（練習）用です。実際のお金は動きません。投資助言ではありません。
